# 🌐 EDIT — сайт для телефона (деплой на Vercel)

Полноценный веб-сайт ассистента EDIT: работает с телефона через **мобильный интернет** из любой точки (ПК не нужен). Пароль для входа: **`gelius`**.

## Что внутри
- `index.html` / `style.css` / `app.js` — чат с EDIT (тёмная «джарвисовская» тема);
- `api/chat.js` — serverless-функция Vercel: проверяет пароль и проксирует запросы к Gemini;
- `manifest.webmanifest` + `icons/` + `sw.js` — можно установить как приложение на телефон (PWA);
- `vercel.json`, `package.json` — конфигурация деплоя.

## Возможности
- 🔐 Вход по паролю **`gelius`** (пароль проверяется на сервере, не в браузере);
- 🎤 Голосовой ввод (распознавание речи Chrome, `ru-RU`) — микрофон наушников;
- 🔊 Озвучка ответов системным TTS телефона → **в наушники**;
- 🎧 **Кнопка наушника = «говорить»** (тап по Gelius начинает распознавание);
- 📴 Экран не гаснет, пока EDIT говорит или слушает (Wake Lock);
- 📲 Устанавливается как приложение («Добавить на главный экран»).

## 🚀 Как задеплоить на Vercel (пошагово)

### Шаг 1 — нужен ключ Gemini (бесплатно)
1. Открой https://aistudio.google.com/apikey
2. Войди аккаунтом Google → **Create API key** → скопируй ключ (вида `AIza...`).

### Шаг 2 — деплой (любой способ)

**Способ A — через GitHub (проще всего):**
1. Создай репозиторий на GitHub и залей в него **всё содержимое этой папки** (не папку `vercel_site`, а её содержимое: `index.html`, `api/`, и т.д.).
2. Зайди на https://vercel.com → **Add New… → Project** → выбери этот репозиторий.
3. Vercel сам определит, что это статический сайт + функция. Нажми **Deploy**.
4. Через ~1 минуту получишь адрес вида `https://твой-проект.vercel.app`.

**Способ B — через терминал (без GitHub):**
```
npm i -g vercel
cd vercel_site
vercel
```
→ войди в аккаунт Vercel, ответь на вопросы (фреймворк — Other, деплой — Yes), в конце получишь URL.

### Шаг 3 — задать переменные окружения
После первого деплоя (или до него):
1. Открой проект на vercel.com → **Settings → Environment Variables**.
2. Добавь:
   - **Name:** `GEMINI_API_KEY` → **Value:** твой ключ из Шага 1;
   - (необязательно) **Name:** `EDIT_PASSWORD` → **Value:** любой пароль (по умолчанию `gelius`).
3. Нажми **Redeploy** (Deployments → ⋮ → Redeploy), чтобы переменные применились.

### Шаг 4 — готово ✅
1. Открой `https://твой-проект.vercel.app` на телефоне (хоть по мобильным данным).
2. Введи пароль **`gelius`**.
3. Пиши/говори — EDIT отвечает и озвучивает в наушники. Надень Gelius, тапни по наушнику — EDIT слушает.

## 🔒 Безопасность
- Пароль хранится на сервере (Vercel env `EDIT_PASSWORD`), по умолчанию **`gelius`** — смени его на свой, если сайт будет публичным.
- Ключ Gemini лежит только на сервере (env `GEMINI_API_KEY`), в браузер не попадает.
- История диалога хранится только в памяти вкладки (sessionStorage — только пароль).

## ⚙️ Настройка
- Модель: env `GEMINI_MODEL` (по умолчанию `gemini-2.5-flash`).
- Язык распознавания речи: `ru-RU` (в `app.js`, переменная `rec.lang`).
