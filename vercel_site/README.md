# 🌐 EDIT — полная веб-копия приложения (Vercel · OpenRouter)

Сайт-копия приложения EDIT, полностью работающий через **OpenRouter**:
- **Мозг (чат)** — LLM через OpenRouter `POST /api/v1/chat/completions`;
- **Голос** — **`fish-audio/s2.1-pro-free:free`** (нейронный TTS через `POST /api/v1/audio/speech`) — ответы звучат настоящим нейронным голосом прямо в наушниках;
- Инструменты (погода/новости/поиск/калькулятор), HUD-орб, wake-word «EDIT», наушники, память, настройки, напоминания.

Работает с телефона через **мобильный интернет** из любой точки — ПК не нужен.

## Вход
- **Пароль** — проверяется на сервере (по умолчанию `gelius`, env `EDIT_PASSWORD`).
- **Ключи уже встроены** (base64 в `api/chat.js`): **Gemini** — мозг (чат), **OpenRouter** — голос (fish-audio). Вводить их при входе не нужно, достаточно пароля. Приоритет: ключ с сайта → env (`GEMINI_API_KEY` / `OPENROUTER_API_KEY`) → встроенный.

## 🚀 Деплой на Vercel
1. Ключ OpenRouter: https://openrouter.ai/settings/keys
2. Залей содержимое папки в GitHub-репозиторий → vercel.com → **Add New → Project** → Deploy (или `npm i -g vercel && vercel`).
3. Vercel → **Settings → Environment Variables** → добавь:
   - `OPENROUTER_API_KEY` — твой ключ `sk-or-v1-…` (**обязательно**);
   - `EDIT_PASSWORD` — свой пароль (по умолчанию `gelius`);
   - `OPENROUTER_MODEL` — модель-«мозг» (по умолчанию `meta-llama/llama-3.3-70b-instruct:free`);
   - `OPENROUTER_TTS_MODEL` — голос (по умолчанию `fish-audio/s2.1-pro-free:free`).
   → **Redeploy**.
4. Открой `https://проект.vercel.app` на телефоне → пароль → пользуйся.

> ⚠️ GitHub блокирует коммиты с настоящими ключами (secret scanning). Ключ задавай через env на Vercel, а не в файлах. Если хочешь «встроить» ключ без env — вставь его в `EMBEDDED_OR_KEY` в `api/chat.js` локально и не пуши в публичный репозиторий.

## Возможности
- 🎛 HUD-орб со статусами (СЛУШАЮ / ДУМАЮ / ГОВОРЮ / НЕТ СЕТИ);
- 🎧 **телефонный режим — управление через наушник:** тапни по кнопке наушника (Gelius) — EDIT начинает слушать; отвечает **только на вопрос после слова «EDIT»**: скажи «EDIT, какой сегодня день?» — EDIT ответит, а без «EDIT» молчит и ждёт следующего тапа;
- 🗣 если сказал просто «EDIT» — EDIT продолжает слушать и ждёт сам вопрос;
- 🔊 ответы — нейронный голос fish (OpenRouter) в наушники;
- 🧰 инструменты: погода, новости, поиск (DuckDuckGo), калькулятор, время;
- 🧠 память (localStorage): имя ассистента, имя пользователя, город, язык, скорость голоса;
- ⏰ напоминания; ⚙️ настройки; 📲 PWA (установка на главный экран) — сайт оптимизирован именно для телефона.

## Структура
- `index.html` / `style.css` / `app.js` — интерфейс и клиент;
- `api/chat.js` — serverless-функция: пароль → инструменты → OpenRouter LLM → fish TTS (mp3 base64);
- `manifest.webmanifest`, `icons/`, `sw.js` — PWA;
- `vercel.json`, `package.json` — конфиг деплоя.

## Как это работает (API)
1. Клиент шлёт `/api/chat` с паролем, историей и профилем.
2. Сервер: проверяет пароль → запускает инструмент (если нужно) → вызывает OpenRouter `chat/completions` (модель-«мозг»).
3. Сервер вызывает OpenRouter `audio/speech` с `fish-audio/s2.1-pro-free:free` → получает mp3 → отдаёт base64.
4. Клиент проигрывает mp3 (нейронный голос). Если аудио нет — фолбэк на системный TTS браузера.
