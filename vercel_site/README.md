# 🌐 EDIT — полная веб-копия приложения (Vercel)

Полноценный сайт-копия приложения EDIT: неоновый HUD-орб, голосовой режим с wake-word «EDIT», наушники, память, настройки и встроенные инструменты. Работает с телефона через **мобильный интернет** из любой точки — ПК не нужен.

## Что умеет (как в приложении)
- 🎛 **HUD-орб** — нажми на орб и говори; статусы: СЛУШАЮ / ДУМАЮ / ГОВОРЮ / НЕТ СЕТИ;
- 🗣 **Wake-word «EDIT»** — режим «всегда слушать»: скажи «EDIT, …» — EDIT ответит (в настройках);
- 🎤 **Голосовой ввод** — распознавание речи (русский/украинский/английский), через микрофон наушников;
- 🔊 **Озвучка ответов** — системный TTS телефона → в наушники; скорость голоса настраивается;
- 🎧 **Наушники** — тап по кнопке наушника (Gelius) = «говорить» (mediaSession/AVRCP);
- 📴 **Wake Lock** — экран не гаснет, пока EDIT говорит/слушает;
- 🧰 **Инструменты** (на сервере): погода (wttr.in), новости (RSS Лента/BBC), поиск (DuckDuckGo), калькулятор, время/дата (из профиля);
- 🧠 **Память** — имя ассистента, твоё имя, город, язык, скорость голоса (localStorage);
- ⏰ **Напоминания** — «напомни через N минут» (уведомления + голос);
- ⚙️ **Настройки** — имя ассистента, имя пользователя, город, язык, скорость голоса, режим всегда-слушать, тест голоса;
- 📲 **PWA** — устанавливается как приложение на главный экран.

## Вход
- **Пароль** — проверяется на сервере (по умолчанию **gelius**, env `EDIT_PASSWORD`).
- **API-ключ Gemini** — необязательно: приоритет ключ с сайта → env `GEMINI_API_KEY` → `EMBEDDED_API_KEY` в `api/chat.js`.

## 🚀 Деплой на Vercel
1. Ключ Gemini: https://aistudio.google.com/apikey
2. Залей содержимое папки в GitHub-репозиторий → vercel.com → **Add New → Project** → Deploy (или `npm i -g vercel && vercel`).
3. Vercel → **Settings → Environment Variables** → `GEMINI_API_KEY` (твой ключ), по желанию `EDIT_PASSWORD` → Redeploy.
4. Открой `https://проект.vercel.app` на телефоне → пароль → пользуйся.

> ⚠️ GitHub блокирует коммиты с настоящими ключами (secret scanning). Задавай ключ через env на Vercel, а не в файлах.

## Структура
- `index.html` / `style.css` / `app.js` — интерфейс и вся логика клиента;
- `api/chat.js` — serverless-функция: пароль, ключ, инструменты (погода/новости/поиск/калькулятор), вызов Gemini;
- `manifest.webmanifest`, `icons/`, `sw.js` — PWA;
- `vercel.json`, `package.json` — конфиг деплоя.

## ⚙️ Настройки
- Модель Gemini: env `GEMINI_MODEL` (по умолчанию `gemini-2.5-flash`).
- Язык распознавания: настройки сайта (по умолчанию `ru-RU`).
- Инструменты определяются по ключевым словам в `api/chat.js` (`detectTool`).
