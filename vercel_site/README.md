# 🌐 EDIT — сайт для телефона (деплой на Vercel)

Полноценный веб-сайт ассистента EDIT: работает с телефона через **мобильный интернет** из любой точки (ПК не нужен).

## Что внутри
- `index.html` / `style.css` / `app.js` — экран входа + чат с EDIT (неоновый «джарвисовский» интерфейс);
- `api/chat.js` — serverless-функция Vercel: проверяет пароль и вызывает Gemini;
- `manifest.webmanifest` + `icons/` + `sw.js` — устанавливается как приложение (PWA);
- `vercel.json`, `package.json` — конфигурация деплоя.

## Вход
- **Пароль** — проверяется на сервере.
- **API-ключ Gemini** — вводится при входе на сайте (поле «API-ключ Gemini»), хранится только на устройстве (sessionStorage) и отправляется вместе с запросом. Можно также задать на сервере через env `GEMINI_API_KEY` — тогда поле на сайте можно оставить пустым? Нет: если env задан, ключ с сайта не обязателен.

## Возможности
- 🎤 Голосовой ввод (распознавание речи Chrome, `ru-RU`) — через микрофон наушников;
- 🔊 Озвучка ответов системным TTS телефона → **в наушники**;
- 🎧 **Кнопка наушника = «говорить»** (тап по Gelius начинает распознавание);
- 📴 Экран не гаснет, пока EDIT говорит или слушает (Wake Lock);
- 📲 Устанавливается как приложение («Добавить на главный экран»).

## 🚀 Как задеплоить на Vercel (пошагово)

### Шаг 1 — ключ Gemini (бесплатно)
1. Открой https://aistudio.google.com/apikey
2. Войди аккаунтом Google → **Create API key** → скопируй ключ (вида `AIza...`).

### Шаг 2 — деплой

**Способ A — через GitHub (проще всего):**
1. Создай репозиторий на GitHub и залей в него **всё содержимое этой папки** (`index.html`, `api/`, и т.д. — не саму папку).
2. Зайди на https://vercel.com → **Add New… → Project** → выбери репозиторий.
3. Vercel сам определит статический сайт + функцию. Нажми **Deploy**.
4. Через минуту получишь адрес `https://твой-проект.vercel.app`.

**Способ B — через терминал:**
```
npm i -g vercel
cd vercel_site
vercel
```

### Шаг 3 — (необязательно) переменные окружения
Vercel → **Settings → Environment Variables**:
- `EDIT_PASSWORD` — свой пароль (по умолчанию **gelius**);
- `GEMINI_API_KEY` — ключ для сервера (не обязателен, если ключ вводится на сайте);
- `GEMINI_MODEL` — модель (по умолчанию `gemini-2.5-flash`).
После изменения — **Redeploy**.

### Шаг 4 — готово ✅
1. Открой `https://твой-проект.vercel.app` на телефоне (хоть по мобильным данным).
2. Введи пароль и свой API-ключ Gemini.
3. Пиши/говори — EDIT отвечает и озвучивает в наушники. Надень Gelius, тапни по наушнику — EDIT слушает.

## 🔒 Безопасность
- Пароль хранится на сервере и не раскрывается клиенту.
- API-ключ хранится только в sessionStorage устройства и не попадает в логи Vercel.
- История диалога — только в памяти вкладки.

## ⚙️ Настройка
- Язык распознавания речи: `ru-RU` в `app.js` (`rec.lang`).
- Тема/цвета: переменные в `style.css`.
