# 🧬 Как сделать чтобы EDIT сам себя переделывал — SELF-EVOLUTION V2

Твоя система **уже умеет** сама себя менять! Тебе не надо писать код вручную — достаточно сказать EDIT голосом или текстом.

---

## 📦 Что уже есть внутри (3 инструмента самовосстановления)

### 1. `self_improve` — главный инструмент эволюции
**Триггеры на русском:**
- "переделай интерфейс" / "переделать интерфейс"
- "добавлять функции" / "добавь функцию" / "добавь возможность"
- "улучши себя" / "улучшать себя"
- "сделай неоновую тему", "поменяй цвет", "добавь кнопку"

**Что умеет V2:**
| action | Что делает | Пример |
|--------|-----------|--------|
| `read_file` | читает любой файл проекта | `ui.py`, `main.py`, `actions/weather_report.py` |
| `list_files` | список файлов в папке | `actions/` , `core/` |
| `edit_file` | **FUZZY** замена — не нужен 100% точный текст! Авто-бекап + проверка синтаксиса | меняет кусок кода |
| `write_file` | создает новый файл с нуля | новый action, новый виджет |
| `redesign_ui` | мгновенная смена цвета `ui_color` + правка `ui.py/hub.py` | `ui_color="#ff00ff"` |
| `add_feature` | добавить новую фичу | `actions/my_feature.py` |
| `create_action` | создает полноценный action в `actions/` | генерация нового инструмента |
| `inspect_code` | grep поиск по коду | найти где `HudCanvas` |
| `backup` | бекап файла | `ui.py` |
| `rollback` | откат к бекапу | восстановить |
| `evolution_log` | история всех изменений | посмотреть что он уже менял |

**Бекапы:** лежат в `config/backups/` с timestamp, последние 20 штук хранятся.

### 2. `create_skill` — навыки НАВЕКИ
**Триггеры:** "делать навыки навеки", "создай навык", "научись новому"

Создает файл в `actions/custom_skills/` + запись в `registry.json`. После перезапуска — автоматически появляется как новый tool в Gemini!

**Пример запроса к EDIT:**
> "Создай навык `translate_ru_en` который переводит с русского на английский через MyMemory API, сделай его навсегда"

EDIT вызовет:
```python
create_skill(
  action="create",
  skill_name="translate_ru_en",
  description="Translate Russian to English",
  parameters_schema='{"type":"OBJECT","properties":{"text":{"type":"STRING"}},"required":["text"]}',
  python_code='''
def run_skill(args, player=None):
    import urllib.parse, urllib.request, json
    text = args.get("text","")
    url = f"https://api.mymemory.translated.net/get?q={urllib.parse.quote(text)}&langpair=ru|en"
    try:
        with urllib.request.urlopen(url, timeout=5) as r:
            return json.loads(r.read())["responseData"]["translatedText"]
    except Exception as e:
        return f"Translate error: {e}"
'''
)
```

### 3. `execute_command` — "полностью что я захочу"
**Триггеры:** "сделай что угодно", "выполни команду", "установи пакет"

Может делать **абсолютно всё** на системе: bash и python.

- `mode="bash"` — терминал: `pip install`, `ls`, `git`, `npm`, файлы
- `mode="python"` — исполняет Python в контексте проекта (есть `BASE_DIR`, `player`, `Path`)

## 🎨 Как переделать интерфейс (UI)

EDIT имеет огромный файл `ui.py` (187k строк) — весь HUD, кнопки, темы.

### Способ 1: Мгновенная смена цвета (самый быстрый)
Скажи:
> "Сделай интерфейс неоново-зеленым"
> "Поменяй цвет на #ff0066"
> "Сделай тему в стиле Cyberpunk, ярко-розовую"

EDIT вызовет:
```json
{
  "action": "redesign_ui",
  "ui_color": "#00ff88",
  "description": "неоновая зеленая тема для HUD"
}
```
Цвет запишется в `config/api_keys.json` -> `ui_color` и применится **мгновенно** через `retheme_all_widgets()` без перезапуска!

Все цвета в `ui.py` привязаны к палитре `C.PRI` — hue-shift пересчитывает всю палитру.

### Способ 2: Правка кода ui.py
> "Добавь кнопку 'Погода' в панель настроек которая показывает погоду в Москве"
> "Сделай орбиту (orb) больше в 1.5 раза и добавь пульсацию"
> "Переделай quick drawer чтобы он был справа шире — 420px"

EDIT вызовет:
```json
{
  "action": "edit_file",
  "file_path": "ui.py",
  "old_text": "self._DRAWER_W = 360",
  "new_text": "self._DRAWER_W = 420",
  "description": "сделал drawer шире для лучшей читаемости"
}
```

### Способ 3: Новый виджет
> "Создай новый виджет погоды в HUD который всегда показывает температуру"

EDIT вызовет `write_file` или `create_action`.

## 🔧 Как добавлять новые функции

### Вариант A: Новый action в `actions/`
Скажи:
> "Добавь функцию которая показывает курс биткоина и говорит его голосом"

EDIT сделает:
1. `read_file` — посмотрит как устроены `actions/crypto_price.py` и `actions/web_search.py`
2. `write_file` — создаст `actions/bitcoin_speaker.py` с функцией `def bitcoin_speaker(parameters, player, speak)`
3. Потом скажет тебе добавить импорт в `main.py` — или сделает сам через `edit_file`

### Вариант B: Навык навеки (рекомендуется)
Скажи:
> "Сделай навык навеки `btc_tracker`"

Отличие от action: навык сразу попадает в `TOOL_DECLARATIONS` через `get_custom_tool_declarations()` и не требует правки `main.py`!

### Вариант C: Полная свобода через bash
> "Установи библиотеку yfinance и сделай навык анализа акций"

EDIT:
```json
{"command": "pip install yfinance", "mode": "bash"}
```
потом создаст skill который использует эту библиотеку.

## 🏗️ Архитектура самоизменения (как это работает под капотом)

```
[ Твой голос/текст ] 
       ↓
[ Gemini Live API — prompt.txt с триггерами на русском ]
       ↓
[ TOOL_DECLARATIONS в main.py — 30+ инструментов ]
       ↓
[ get_all_tool_declarations() — подмешивает кастомные навыки из registry.json ]
       ↓
[ JarvisLive._execute_tool() — диспетчер ]
       ↓
[ actions/self_improve.py — V2 engine ]
   ├─ _fuzzy_find() — находит похожий кусок даже если не 100% совпадение
   ├─ _backup_file() — сохраняет в config/backups/ перед каждой правкой
   ├─ _validate_python_syntax() — не даст сломать Python
   ├─ _log_evolution() — пишет в config/evolution_log.json
   ├─ create_skill() — навеки
   ├─ self_improve() — правки
   └─ execute_command() — всё что захочешь
```

**Ключевое:** `prompt.txt` содержит:
```
- Permanent Skills (create_skill): ... 'делать навыки навеки'
- Self-Improvement & UI Modification (self_improve): ... 'переделывать интерфейс', 'добавлять функции возможности'
- Unlimited Capability (execute_command): ... 'полностью что я захочу'
```

Поэтому Gemini **знает** что должен вызывать эти tools когда ты говоришь эти фразы на русском!

## 🚀 Что я только что улучшил в твоём коде (V2)

1. **Fuzzy поиск** — теперь `edit_file` не требует точного текста, находит похожий блок с помощью difflib (порог 85%)
2. **Автобекапы** — перед каждой правкой копия в `config/backups/` (последние 20)
3. **Rollback** — `rollback` и `list_backups` чтобы откатиться если что-то сломал
4. **Evolution Log** — `config/evolution_log.json` — история всех мутаций
5. **Новые actions** — `create_action`, `backup`, `evolution_log`
6. **Защита от опасных команд** — блокирует `rm -rf /` без `--force`
7. **Более длинные логи** — до 10KB вывода, truncation
8. **TOOL_DECLARATIONS обновлён** — теперь описание включает русские триггеры и новые actions

## ✅ Чеклист чтобы всё заработало

1. Убедись что `config/api_keys.json` существует (API ключ Gemini)
2. Запусти `python main.py`
3. Скажи одну из фраз:
   - "Переделай интерфейс на фиолетовый"

5. Если сломал — `rollback` или смотри бекапы в `config/backups/`
